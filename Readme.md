# 🎬 YouTube Clone (MERN Stack Project)

A full-featured **YouTube-like video sharing platform** where creators can upload content and users can interact with it seamlessly.

---

##  Features

-  Creators can upload videos
-  Users can watch videos
-  Like videos
-  Comment on videos
-  Subscribe to channels
-  Get notifications when new videos are uploaded

---

## 🧠 Project Overview

This project aims to replicate the core functionality of YouTube using the **MERN Stack (MongoDB, Express.js, React.js, Node.js)**. It focuses on building scalable backend APIs, efficient database models, and an interactive frontend.
